# LighRender
一个基于Web的轻量级Live2D渲染器

## 功能

> 🎨 极简的 Live2D 模型 Web 渲染器

## 模型来源

> 22娘、33娘的 Live2D 模型由 [bilibili-haruna](https://github.com/52cik/bilibili-haruna) 获得

> 罗小黑的 Live2D 模型由 [lpk-unpacker](https://github.com/spawner1145/lpk-unpacker) 解包 [@躺师傅轻食小炒](https://space.bilibili.com/11407406) 提供的罗小黑Live2D模型LPK文件获得
